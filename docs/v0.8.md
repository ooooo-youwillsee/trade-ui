# v0.8

## Summary

`v0.8` 汇总了 `v0.7` 之后的马丁策略增强，覆盖合约马丁和现货马丁。该版本进一步统一层级止盈收益的累计投资口径，完善层级明细布局和默认参数，并新增 Gate、Bitget 执行平台差异及 Gate 自由参数模式，让用户既可以按倍数自动生成仓位，也可以逐层配置加仓价差和下单份数。

## Key Changes

- 层级收益与明细展示：
  - 止盈毛利润和净利润统一基于该层累计持仓与累计投资额计算，避免将单层新增订单误作完整持仓收益。
  - 触发价增加相对入场价的涨跌比例；层级明细按触发、仓位、累计持仓、均价、止盈和利润重新排版。
  - 移除首个指标卡的特殊边框，统一单元格对齐，并处理窄屏和超长数值的可读性。
  - 核心指标展示当前已执行层对应的止盈毛利润和止盈净利润。
- 价差倍数与默认参数：
  - 新增加仓价差倍数，并将原“加仓倍数”明确命名为“加仓金额倍数”。
  - 默认触发幅度、金额倍数和价差倍数均为 `1.1`，默认最大层数调整为 `25`。
  - 合约首单保证金默认调整为 `2 USDT`，杠杆倍数默认调整为 `10x`。
- 执行平台与自由参数：
  - 新增执行平台参数，默认使用 Gate；合约和现货共用同一平台语义。
  - Gate 普通模式按上一层触发价逐层复利计算价差；Bitget 按入场价累计各层价差。
  - Gate 新增自由参数模式，可逐层设置相对上一层的价差百分比和相对首单的下单份数。
  - 自由参数首层固定为 `0% / 1份`，支持 `1-99` 层、末尾添加或删除、直接输入和步进按钮。
  - 首次开启自由参数时从普通设置生成等价层级；切换 Bitget 会关闭自由模式但保留 Gate 自由配置。
- UI、存储与维护性：
  - 合约和现货表单新增平台选择、自由参数开关及响应式逐层编辑器；结果页动态展示实际生效的平台和参数模式。
  - 马丁本地存储写出格式升级至 `v5`，继续忽略历史版本号并使用当前默认参数补齐缺失字段。
  - 自由参数数组采用深度规范化与复制；损坏策略逐条跳过，不影响同一存储中的其他有效策略。
  - 核心计算、手续费、强平估算、兼容加载、自由参数交互和 Vue 状态管理补充详细中文注释。
