# v0.9

## Summary

`v0.9` 汇总了 `v0.8` 之后的策略交互增强。马丁自由参数与普通比例参数改为相互独立，并补充层级价格相对触发价的涨跌幅；同时为马丁、普通合约网格、现货网格和双腿对冲合约网格增加统一、可访问的参数与结果 Tip。

## Key Changes

- 马丁自由参数与层级价格：
  - Gate 自由参数首次开启时只创建固定的 `0% / 1份` 首单层，不再从普通比例参数自动转换。
  - 关闭自由模式、切换执行平台、应用快捷预设、复制、重置和本地恢复时，普通参数与自由层级分别保存，避免相互覆盖。
  - 层级明细中的持仓均价和止盈价增加相对本层触发价的涨跌幅展示。
- 通用策略 Tip：
  - 抽取共享 Tip 标签组件，统一桌面悬停、键盘聚焦、移动端点击、`Esc` 关闭及视口防越界行为。
  - 马丁、普通合约网格和现货网格的表单参数、核心指标、风险状态、持仓收益及挂单明细均提供详情说明。
  - 双腿对冲网格补齐多空腿参数、场景价格、场景仓位、强平估算、资金缺口、需补保证金及挂单结果说明。
  - Tip 文案根据现货/合约、做多/做空/中性、等差/等比和当前/场景口径动态生成，并明确手续费、收益和简化强平估算边界。
