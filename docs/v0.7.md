# v0.7

## Summary

`v0.7` 汇总了 `v0.6` 之后的马丁策略重构，覆盖合约马丁和现货马丁。该版本将入场价与当前价拆分，重建执行层数和浮动盈亏口径；移除执行规则、资金上限及维持保证金率输入；并补充基于手续费的层级止盈毛利润与净利润展示，同时优化参数表单和结果区域布局。

## Key Changes

- 入场价、当前价与执行层数：
  - 新增独立的 `entryPrice`，第一层固定按入场价成交，并始终视为已执行。
  - 后续层级价格以入场价和触发幅度等比生成，不再随当前价变化。
  - `currentPrice` 不再生成层级价格，改用于判断当前执行层数、聚合当前持仓、计算实时浮动盈亏与合约强平缓冲。
  - 结果接口使用 `currentExecutedLayers`，明确表达当前已经执行到的层级。
- 删除旧执行与资金约束：
  - 删除执行规则区域及 `includeInitialOrder`、`restrictByCapital` 等相关逻辑。
  - 删除资金上限、可执行层数、资金缺口和不可执行状态等计算与展示。
  - 删除维持保证金率输入；合约改用“已执行保证金 + 追加保证金”作为亏损预算的简化强平模型。
- 参数与结果 UI 优化：
  - 行情价格改为入场价、当前价各占一行，当前价同时显示相对入场价的涨跌比例。
  - 合约策略参数统一为单列布局，并按触发幅度、止盈比例、杠杆倍数等顺序组织。
  - 百分比单位固定显示在字段行末，单边手续费率移动至参数区域最后一行。
  - 核心指标卡删除估算强平价与强平距离，合约风险区仍保留强平缓冲状态；层级明细默认折叠，减少首屏信息密度。
  - 策略列表摘要改为展示当前执行层数和浮动盈亏；合约补充估算强平价，现货补充当前止盈价。
- 层级盈亏与手续费：
  - 层级浮动盈亏改为按该层触发价、累计持仓均价和累计数量计算的“触发时浮动盈亏”。
  - 每层止盈收益区分毛利润与净利润，并仅按该层新增订单计算。
  - 新增单边手续费率参数，默认值为 `0.02%`；净利润同时扣除开仓手续费和止盈平仓手续费。
  - 现货当前持仓和满层场景统一使用明确的毛利润、净利润及对应收益率口径；合约不再返回或展示当前止盈和满层止盈汇总。
  - 增强数值边界校验，拒绝价格、加仓金额、浮动盈亏或追加保证金出现非有限结果。
- 本地策略存储：
  - 马丁策略存储版本升级至 `v3`，保存、复制和预设均包含 `entryPrice` 与 `feeRate`。
  - 仅恢复结构有效的 `v3` 数据；`v2` 及更早版本、裸数组、无版本或损坏数据不迁移并直接清理。
  - 这是破坏性存储升级：合约与现货分别检查各自的本地存储；任一市场的数据版本不兼容或包含损坏策略时，该市场保存的马丁策略会被整体清空，需要重新创建。
