# v0.6

## Summary

`v0.6` 汇总了 `v0.5` 之后的策略列表体验增强、网格收益展示增强，以及网格最小成交数量和固定成交数量口径优化。本版本让现货网格、合约网格和对冲合约网格统一按“每格成交数量一致”的方式计算订单、持仓、保证金和收益，并移除了已经不再参与计算的仓位递增功能。

## Key Changes

- 策略列表体验增强：
  - 新增策略列表搜索能力，便于在较多本地策略中快速定位目标策略。
  - 优化合约网格列表指标，让列表摘要更贴近合约网格的风险和资金占用信息。
- 网格收益展示增强：
  - 网格明细展示毛利和净利，区分手续费前后的单格收益。
  - 结果页继续保留单格收益率、区间振幅等关键指标，便于比较不同网格参数。
- 最小成交数量：
  - 新增并保存 `minTradeQuantity`，支持表单编辑。
  - BTC 默认 `0.0001`，ETH 默认 `0.001`，其他名称默认 `0.01`。
  - 历史策略缺少该字段时按策略名或腿名称推断默认值。
- 固定成交数量口径：
  - 现货网格按 `investment / gridCount / upperPrice` 计算理论单格数量。
  - 合约网格按 `investment * leverage / gridCount / upperPrice` 计算理论单格数量。
  - 理论数量不能整除最小成交数量时，向下取最大可成交份数；不足一个最小成交单位时提示错误。
  - 所有网格订单使用同一个 `tradablePerGridQuantity`，订单金额、合约名义价值和保证金按实际网格价格反推。
- 对冲合约网格：
  - 多头腿和空头腿分别使用各自的投入、杠杆、最高价和最小成交数量计算固定单格数量。
  - 场景推演、已平仓收益、未平仓收益和强平估算都沿用固定成交数量口径。
- 删除仓位递增：
  - 移除现货、合约、对冲腿表单中的“单格递增”输入。
  - 删除仓位递增常量、默认值、保存字段、结果摘要和测试数据。
  - 历史策略中的递增字段会在重新归一化和保存时自然丢弃。
- 代码可读性：
  - 为最小成交数量、固定成交数量、合约保证金反推和对冲场景推演补充中文注释。
